# Beeskilled Internship – Week 1

This repository contains my Week 1 assignments and mini project completed as part of the BeeSkilled Internship.

## Topics Covered

- C Programming Basics
- Syntax, Variables and Data Types
- Input and Output
- Operators
- If-Else Statements
- Loops
- Switch Case

## Assignments

### Assignment 1 – Hello World
A simple C program to print "Hello World."

### Assignment 2 – Sum of Two Numbers
A C program that takes two numbers as input and calculates their sum.

### Assignment 3 – Even or Odd
A C program that checks whether a given number is even or odd.

### Assignment 4 – Fibonacci Series
A C program that prints the Fibonacci series up to n terms.

## Mini Project

### Simple Calculator Using Switch Case

A basic calculator developed in C using switch-case statements.

The calculator performs:

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
